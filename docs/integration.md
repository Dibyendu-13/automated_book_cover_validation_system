# Integration Details

## Google Drive

Expected trigger:

- Monitor a folder for new uploads
- Accept `ISBN_text.pdf` or `ISBN_text.png`
- Extract the ISBN from the filename

## Airtable

Suggested fields:

- Book ID
- Detection timestamp
- Issue type and severity
- Status
- Confidence score
- Visual annotations URL
- Correction instructions
- Revision tracking

## Email

Suggested content:

- Personalized greeting
- Status line
- Bullet list of issues
- Step-by-step fixes
- Resubmission timeline
